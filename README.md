## What it does

`main.py` (Python 3, standard library only, no network) writes
a one-line pickup line to `/output/entry.txt` — a vending machine
flirting with a passing human, in the machine's own voice:

> I've dropped 214 snacks for strangers, but yours is the only one I ever hoped would get stuck — come back tomorrow, I'll jam on purpose.

The entry is 136 characters long. The joke turns on the machine's own
world: its classic failure — a snack getting stuck, a jam — bent into
a romantic gesture, with a concrete number (214 snacks) and the twist
in the final words. It stays charming rather than creepy: the machine
sabotages only itself, offering to jam on purpose so the human comes back.
